# 基本面量化与公司研究：学习项目

以贵州茅台（600519）为样例，完成财报获取、字段核对、指标计算与初步公司研究，学习如何用盈利能力和现金流数据分析企业。当前以 2024 年为主，并与 2023 年比较；尚未开展选股、组合或历史回测。

首次配置环境可阅读 [START_HERE.md](START_HERE.md)。进度更新：2026-10-16。

## 核心结果与计算口径

| 指标 | 2024 年结果 | 公式 |
| --- | ---: | --- |
| 销售净利率 | 52.27% | 合并净利润 / 营业收入 |
| 经营现金流净额 / 净利润 | 103.50% | 经营活动现金流量净额 / 合并净利润 |
| 简化 ROE | 38.43% | 归母净利润 / 期初期末平均归母净资产 |

净利润与归母净利润不能混用。简化 ROE 使用 2023 年末、2024 年末归母净资产，不等同于年报披露的加权平均 ROE（36.02%）。年度分析采用完整年度数据，季度累计数不能直接当作单季度数。

初步发现：收入与利润同步增长，净利率较 2023 年小幅回落；经营现金流相对利润有所改善，但包含财务公司资金归集的影响；经销商预付款减少值得继续跟踪。证据、年报页码与结论边界见研究笔记。

## 本地运行

在项目根目录打开终端。已有 `.venv` 时直接激活；新环境按以下命令创建并安装依赖：

```bash
python3.13 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-lock.txt
```

`requirements.txt` 列出主要依赖，`requirements-lock.txt` 记录当前环境实际版本；不同操作系统或 Python 版本的兼容性仍需检查。

已有完整原始数据时，运行：

```bash
python scripts/calculate_metrics.py --year 2024
```

脚本默认选择 `data/raw/` 下最新的完整 `sh600519_*` 三表目录。复现本笔记所用的本地快照，应明确指定目录：

```bash
python scripts/calculate_metrics.py --year 2024 --data-dir data/raw/sh600519_20261013T130809447847Z
```

预期核心输出：

```text
销售净利率：52.27%
现金流质量：103.50%
简化 ROE：38.43%
```

原始 CSV 与年报 PDF 仅保留在本地，不纳入 Git。新副本需要先联网获取三表：

```bash
python scripts/fetch_financials.py --all
```

成功后运行计算脚本，并按数据字典重新核对。接口返回的是历史报表，重新抓取的内容可能因上游修订而不同，不能保证与 2026-10-13 的快照完全一致。研究笔记中的年报链接指向本地 PDF，新副本还需自行获取该年报；正式下载来源待补录。

## 验证范围与局限

本地已有三表及抓取元数据；已在项目虚拟环境中重跑 2024 年指标计算，结果与研究笔记一致。关键字段已与本地年报核对。本次整理未重新测试上游联网获取，接口未来可用性与数据修订情况需另行检查。
